## Fourier Transform {#fourier-transform-1}
- Transforms a continuous-time function to a continuous frequency function to determine a signal spectrum
	- Time -> Frequency

$$X(j\omega) = \int_{-\infty}^{\infty}x(t)e^{-j\omega t} \ \mathrm{d}t$$

- Signal must be absolutely integrable
- Can be determined using the integral definition or <cite class="cite">table <span class="cite-src">[Fourier transform table (course handout)]</span></cite>
